# B20 S13 — Tablero de control

S13 consolida información de las capas financieras existentes para entregar una vista mensual única.

Fuentes:
- S08: gastos operacionales
- S10: créditos personales
- S11: presupuesto e ingresos

Indicadores:
- Meta mensual
- Ingreso registrado
- Gasto real
- Saldo del período
- Presupuesto planificado
- Crédito pendiente
- Cumplimiento de meta

No modifica las capas anteriores.
No requiere SQL.
