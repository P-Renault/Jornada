# B20 S12 — Proyección y escenarios

S12 toma los datos locales de S11 y permite proyectar el resultado mensual bajo tres escenarios:
- Conservador
- Base
- Expansivo

Parámetros:
- jornadas proyectadas
- neto objetivo por jornada
- variación porcentual

No modifica S01-S11.
No requiere SQL durante validación.
