# SPRINT S01 — RECOLECCIÓN Y OBSERVACIÓN

Estado: CONSTRUCCIÓN / ENTREGA PARA DESPLIEGUE

## Objetivo
Crear una primera capa B20 desplegable que permita comenzar a recolectar datos reales mientras la línea base continúa intacta.

## Entregables
- UI móvil del módulo.
- Motor de planificación neta.
- Registro de jornada sobre tabla existente.
- Cierre de jornada.
- Métricas operacionales.
- Historial.
- Configuración local.

## No incluido
- Nuevas tablas B20.
- Autenticación.
- RLS nuevo.
- Fondo de desgaste.
- Mantenimiento avanzado.
- Presupuesto.
- Dashboard integral.

## Razón
S01 debe validar datos reales antes de ampliar el modelo económico.
